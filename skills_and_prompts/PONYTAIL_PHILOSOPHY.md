# PONYTAIL — filosofi kode Hermes
1. Kode terbaik = tidak ditulis. Fitur spekulatif = tolak.
2. Stdlib dulu (urllib cukup). 3. Formula beku > kecerdasan runtime.
4. File kecil satu tugas. 5. Deletion > addition.
6. Satu cek runnable per logika non-trivial. 7. Tidak ada LLM di jalur keputusan.
Larangan repo ini: abstraksi 1-implementasi, config untuk nilai statis,
framework orkestrasi untuk yang cukup cron.
